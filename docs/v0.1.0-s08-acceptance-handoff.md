## Changes and comparison packet

The [release notes](v0.1.0-release-notes.md) flag S08's behavior change. Startup now
reconciles identity references against a successful complete storage inventory before
serving. It removes missing-dataset authority, revokes bound installations and device
codes, and disables fixed-policy issuers that name any missing dataset. It preserves
unaffected data/account/server rights, leaves replacement datasets unowned, and fails
startup if inventory or registry persistence fails. No schema migration or protocol/
vector change was introduced by S08.

  21 discovery vectors. Retained values/comparisons/identifiers are byte-identical
  to rc.4 and alpha.28; both compatibility vector files are byte-identical to c46beb0.

  `5691f26bf50f52b625b18fb2b9e2fb9959b59d3b`; the local rc.4 tag resolves to that
  exact commit. The existing rc.4 comparison therefore covers its declared accepted
