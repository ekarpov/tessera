Share read access

A share limits the guest's account, not only the sign-in named here: every sign-in that account already has on this dataset is narrowed now, and every one it obtains later — a new token, an application approved on another device — inherits the same types. Guests are read-only. A type grant authorizes queries over exactly the named concrete types; references never widen it, and changing a share invalidates pages already issued. An account that writes to this dataset cannot be shared with: that would make a writer read-only everywhere, which is a different decision.
